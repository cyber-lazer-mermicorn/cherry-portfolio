# Security

## Policy

This is a static portfolio site. No user data is collected or stored.

## Scope

- No authentication required
- No forms or user input
- No API calls from client-side
- No tracking without consent

## Reporting

If you find a security issue, please contact Cherry directly through GitHub.

## Best Practices

- Content Security Policy headers
- HTTPS enforcement
- No sensitive data in source code
- Regular dependency updates
