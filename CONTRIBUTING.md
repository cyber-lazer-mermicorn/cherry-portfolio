# Contributing

## Guidelines

1. All changes must maintain the glass morphism design language
2. Project links must point to live proof artifacts, not stubs
3. No empty claims — every project entry must have verified content
4. Responsive design must work on all screen sizes
5. Performance budgets: < 100KB total page weight

## Design System

- Colors: Cyber Lazer palette (neon accents on dark backgrounds)
- Typography: Modern sans-serif with good readability
- Spacing: Consistent 8px grid system
- Components: Glass morphism cards with subtle animations

## Deployment

- Push to main triggers Vercel deployment
- Preview deployments for pull requests
- Lighthouse scores must be > 90 on all metrics
